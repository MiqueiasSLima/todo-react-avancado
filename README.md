Aplicação utilizando as ferramentas do REACT para criar uma To do List, exemplos de ferramentas usadas:

- useState;
- useContext;
- useMemo;
- useEffect

Utilizar o react no Visual Studio para a aplicação funcionar,
Escrever os seguintes linhas de código no terminal do Visual Studio:

npm install -> instalar os pacotes necessários para rodar a aplicação
npm run dev -> comando para executar a aplicação
